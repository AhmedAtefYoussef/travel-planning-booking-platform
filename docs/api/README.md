# API documentation

The live contract is Swagger UI at `http://localhost:3000/api/docs` (brief section 7.1: the backend is
evaluated through Swagger). CI generates `openapi.json` on every PR and publishes it as the `openapi`
workflow artifact. The Swagger demo order for the Milestone 1 evaluation, per role, with the Stripe CLI steps, is in the root [README](../../README.md#run-the-milestone-1-demo-in-swagger).
